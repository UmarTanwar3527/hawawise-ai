## Fixed

| Severity | Finding | Fix |
| --- | --- | --- |
| High | Stored AQI history was overwritten with averages from as few as 16 hours: each run recalculated older hours from a truncated 26 h window. | Fetch 30 h and calculate only hours whose full 24 h window is inside the fetched data (`hoursWithCompleteWindow`). Verified live: new values use 23/24 hours (the gap is in the source). |
| High | A failed data-source lookup returned "no data", which was then cached as an honest-looking empty state. | Query errors now throw and show the error state. A missing source has its own message. |
| High | Map area links were inside an SVG marked `role="img"`, so they were hidden from assistive technology. They also had no `href`. | Real SVG `<a href>` links inside a labelled group. Modifier clicks keep native behaviour. |
| Medium | Default privileges would expose future tables, views and functions to `anon`/`authenticated`. | Migration 007 revokes the defaults, and tests check new tables and views. |
| Medium | Direct Data API writes (reports, media, messages, uploads) had no abuse limits. | Per-user quotas in the database (SQLSTATE `P0429`), plus at most 5 images per report in storage. |
| Medium | The public API cache could be bypassed with extra query parameters, and unknown slugs always reached the database. | API reads use a server cache keyed only on validated, known slugs. Unknown slugs get 404 from the cached area list. |
| Medium | The nearest station was used even when its data was days old and a fresh station was nearby. Readings without values could be selected. | `chooseStation` prefers fresh stations. One batched query with an inner join on pollutant values (also cuts per-station round trips). |
| Medium | Data age and staleness were frozen at cache time. | Recomputed at request time (`withCurrentFreshness`, `connection()`). |
| Medium | Forecasts had no staleness flag, and "issued at" was shown as a model run time. | Shows the fetch time, with a Stale flag after 12 h. |
| Medium | Providers ran one after another, so a slow OpenAQ could starve Open-Meteo within the 60 s limit. | Providers run in parallel. Database errors are reported by code only. |
| Medium | ppb/ppm values whose units look mislabelled were shown as numbers (for example "CO 1.2 ppb"). | The number is hidden with an "unit under verification" note. |
| Medium | Forecast "vs today" compared against a partial day. | Compared against the first full day, and partial days are labelled. |
| Medium | Area selector navigated on change (WCAG 3.2.2), and its border contrast was 1.5:1. | Explicit form with a Show button (works without JavaScript), a border token at 3:1 or more, and `useId`. |
| Low | Storage deletes were allowed on reports under review, with loose path depth. | Policy requires an open report and an exact `<user>/<report>/<file>` path. |
| Low | Avatar URLs accepted any scheme from signup metadata. | https-only constraint, and sanitised at signup. |
| Low | The cron endpoint revealed configuration before authenticating. | Authenticates first. |
| Low | `db.sh` passed the database password in process arguments to `psql`. | `psql` now uses `PG*` environment variables. |
| Low | Assorted accessibility and type issues: `aria-label` on a span, `h2`-only 404 page, unvalidated `calculation_details`, `as` cast on category, "No data" on an unbuilt feature, invalid timestamps accepted, coverage over 100% failing writes. | Fixed. Shared Zod schema for calculation details, `isCpcbCategory` guard, ISO timestamp validation, and coverage clamped. |
| — | No HSTS header. | Added. |

## Accepted or deferred (with reason)

| Item | Decision |
| --- | --- |
| Content-Security-Policy | Deferred until Maps, Supabase Auth and user-generated content define the needed origins. Required before any user content is rendered. |
| CPCB O₃/CO 8-hour aggregation (trailing vs maximum in 24 h) | Unconfirmed. Kept as trailing 8 h and documented. Verify against the CPCB 2014 primary document. |
| OpenAQ ppb unit anomaly | Values stored as reported, hidden in the UI and excluded from the AQI until checked against the CPCB dashboard. |
| Unknown dashboard area returns HTTP 200 (not-found UI + `noindex`) | Accepted. Streaming sends the shell before the area is checked. The API returns a proper 404. |
| Per-IP rate limiting of public endpoints | Server cache plus CDN for now. Add edge or WAF rate limiting at deployment. |
| Supabase CLI receives the database URL as an argument | CLI limitation. Run database scripts on an unshared machine. |
| Storage delete policy is not covered by pgTAP | Supabase blocks direct SQL deletes. Test through the Storage API when report upload is built. |
| Remote auth settings (password length, email confirmation) | Configure in the Supabase dashboard when authentication is built. |
| Service-layer tests with a fake Supabase client, seeded e2e data, automated axe checks | Recommended next. The e2e tests currently read live data and skip parts when it is empty. |
| Shared domain types imported upward by `src/services`; `@supabase/ssr` clients unused until auth; raw Tailwind colours in a few warnings | Low impact. Tidy during the auth and AI work. |
| Ingestion is not scheduled | Schedule hourly after deployment. Until then, data is only as fresh as the last manual run. |
